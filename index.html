Architettura operativa in quattro moduli. Four core operational modules.

Ogni funzione risponde a un compito specifico, senza sovrapposizioni o complessità superflue. Each component serves a distinct purpose, without redundant features or unnecessary complexity.

1. Triage e prioritizzazione automatica 1. Automated Triage & Prioritization

I messaggi in arrivo vengono analizzati per stabilire mittente, contesto e urgenza operativa. I contatti prioritari vengono posti in primo piano, separandoli da newsletter e comunicazioni accessorie. Incoming communications are assessed for sender context, urgency, and actionable requests. Priority clients are placed at the top, cleanly separated from newsletters and notifications.

2. Bozze contestuali e controllo manuale 2. Contextual Drafts & Manual Control

L'IA elabora la bozza di risposta pertinente. Il testo può essere modificato, ridotto o approvato. L'applicazione non procede a nessun invio senza un comando manuale confermato dell'utente. AI prepares a coherent draft response. The text can be inspected, revised, or approved. The application never performs automated dispatch without explicit user confirmation.

3. Pianificazione da testo naturale 3. Natural Language Scheduling

Rileva le scadenze indicate nei messaggi oppure riceve istruzioni scritte in linguaggio naturale (es. «Fissa mezz'ora con Luca venerdì»). Sincronizza l'evento direttamente su Apple Calendar via EventKit. Detects deadlines within message bodies or receives written natural instructions. The event is proposed directly to the native Apple Calendar using EventKit without manual form-filling.

4. Trasparenza sui consumi computazionali 4. Local Compute & Cost Transparency

Tutte le metriche d'uso restano registrate sul Mac: conteggio dei messaggi analizzati, percentuale di modifiche applicate e costo computazionale effettivo dei modelli linguistici, visibile senza ricarichi. All usage metrics are maintained on device: volume of processed messages, draft edit frequency, and direct compute costs for language model calls, tracked without hidden fees.

Infrastruttura locale e riservatezza dei dati. Local infrastructure and data security.

Progettato specificamente per le garanzie di sicurezza dell'ambiente macOS. Engineered strictly to conform with macOS platform security guarantees.

Zero server intermediari No Intermediary Servers

I messaggi non transitano né risiedono su server proprietari. L'archivio dati vive interamente nella memoria locale del dispositivo dell'utente. Communications are never stored on proprietary external servers. Your working database resides entirely on local device storage.

Portachiavi di sistema Apple Apple Keychain Storage

I token di autenticazione e le credenziali di accesso ai canali sono salvati nel Portachiavi protetto hardware del Mac, mai memorizzati in chiaro. Authentication tokens and access credentials are secure inside the hardware-backed Apple Keychain, never exposed in plain text.

Nessun addestramento dati Zero Data Training

Le conversazioni vengono inviate ai modelli linguistici unicamente per l'elaborazione del singolo prompt, senza essere impiegate per il training di modelli terzi. Content submitted to language models is processed solely per explicit request, and is never used to train third-party machine learning models.
